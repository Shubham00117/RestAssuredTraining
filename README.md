# API Testing with Rest-Assured

## 🚀 Overview
Laboratory and training scripts for mastering API automation using the Rest-Assured library.

## 🛠️ Tech Stack
- **Tools:** Rest-Assured, Java, TestNG, JSONPath
- **Design Pattern:** Industry Standards
- **Reporting:** Built-in Reporting / Logs

## ✨ Key Features
- CRUD operation validation
- Auth handling (Basic, OAuth)
- Payload parameterization
- Schema validation
